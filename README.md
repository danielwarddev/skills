# My skills

A collection of common .NET skills I currently use across my projects. Meant to be generalized enough to be able to drop in to any .NET project.

| Skill | Description |
| --- | --- |
| [csharp-standards](csharp-standards/SKILL.md) | General C# standards for things like creating types, writing tests, project structure, and more. |
| [blazor-frontend](blazor-frontend/SKILL.md) | Blazor Server front-end patterns, including component architecture, rendering performance, and bUnit component tests. |
| [mutation-testing](mutation-testing/SKILL.md) | Runs Stryker.NET mutation tests and categorizes potential fixes into buckets based on priority. |
| [spec-creation](spec-creation/SKILL.md) | Creating user-story-driven feature specification documents broken into small, reviewable slices. |
| [spec-execution](spec-execution/SKILL.md) | Implementing specs created with the spec-creation skill. |
| [skill-portability-audit](skill-portability-audit/SKILL.md) | Made for this repo to audit skills. Helps ensure that a skill is generalized so it can put into any project (no real project/folder names, general examples instead of project-specific ones, etc). |
